VISCORD

A lightweight Discord-inspired chat application built with Python.

👋 Welcome to VISCORD

VISCORD is a chat application created by Vasudev as a learning project.

What started as a small experiment slowly grew into a real application with public chat, private servers, voice messages, cloud storage, user presence tracking, automatic updates, and much more.

The code may not be perfect, but every version represents new things learned, bugs fixed, and features added.

---

🚀 Current Version

VISCORD v2.3.3

VISCORD uses "VERSION.txt" to detect and install updates automatically.

✨ Features

- Real-time messaging
- Public cloud chat
- Private servers with custom UIDs
- Voice / audio clip messages
- Online, idle, and offline presence system
- Typing indicators
- Join and leave notifications
- Local message history (SQLite)
- Cloud message storage (Supabase)
- Emoji shortcuts
- Random server UID generator
- Automatic dependency installation
- Automatic update checking
- One-click launcher
- Lightweight desktop interface
- Built entirely with Python

---

🖥️ Getting Started

Getting started is simple.

1. Download VISCORD.
2. Run "Launch.bat".
3. Enter a username.
4. Join a server.
5. Start chatting.

That's it.

The launcher automatically:

- Checks for updates
- Downloads updates when available
- Installs required dependencies
- Launches VISCORD

You don't need to install Python packages manually.

---

🌐 Server Types

Public Server

The public server uses cloud storage and allows everyone to chat together.

Private Servers

Create your own private server using a custom Server UID.

Anyone using the same UID joins the same server.

---

🎤 Voice Messages

VISCORD supports audio clip messages.

Record your voice directly from the app and send it to other users in real time.

---

👥 Presence System

VISCORD includes:

- Online status
- Idle status
- Typing indicators
- Join notifications
- Leave notifications

So you can always see who's active.

---

💾 Data Storage

Local Storage

Private server messages are stored locally using SQLite.

Cloud Storage

Public messages are stored in the cloud using Supabase.

---

🔄 Automatic Updates

VISCORD checks for updates every time it starts.

If a new version is available:

- The update is downloaded automatically
- Files are updated automatically
- VISCORD launches normally

No manual updating required.
